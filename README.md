# 🇹🇷 Şehitlerimiz

Türkiye'deki şehit kayıtlarını `sehitlerimiz.org.tr` kaynağından alınan veriyle
saklayan proje.

## Veri

- Kaynak: https://sehitlerimiz.org.tr/
- Kayıt sayısı: 103.791
- Dosya: `sehitler.csv`
- Kaynakta bulunan alanlar:
  - ad
  - baba_adi
  - rutbe
  - memleket
  - dogum_yeri
  - dogum_yili
  - sehadet_tarihi
  - donem_cephe
  - kaynak
  - sayfa

**Önemli:** Veri dosyası kaynaktaki tüm kayıtları içerir. Şehadet tarihi boş olan
kayıtlar da korunmuştur; bu kayıtlar iPhone takviminde belirli bir güne
zorla yerleştirilmemelidir.

## iPhone Takvimi

Takvim için ayrı olarak, `sehadet_tarihi` bulunan kayıtlar `.ics` formatına
dönüştürülebilir. Takvim etkinlikleri Tüm Gün ve yıllık tekrarlı olarak
oluşturulabilir.
